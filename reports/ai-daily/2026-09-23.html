GPT-6 Sol/Luna 与 Opus 5.5 推动降本，比较单位应从 token 转向完成任务

事件OpenAI 发布 GPT-6 Sol 与 Luna，官网原始日期为9月22日；所附 OpenAI 账号完整原帖发布时间对应北京时间9月23日02:12:13。每百万输入／输出 token，Sol 定价为2／10美元，Luna 为0.10／0.50美元。官方以 GPT-5.6 的促销定价为基准宣传降价50%，不能把这个口径无差别套到每一个计费项目。模型进入 API、Work 和 Codex，Work/Codex 的模型与 Chat 中的选择相互独立。发布公告、原帖记录

同一公告还改进提示词缓存：缓存读取享受九折减免，并允许部分配置变化时保留此前缓存。Anthropic 官网9月22日发布的 Opus 5.5 则将每百万输入／输出价格设为4／20美元；其“典型工作负载成本降低40%”是相对 Opus 5 的官方任务测算，不等于全部单价下降40%。两家性能提升均为厂商声明，本期未进行独立横评。OpenAI缓存说明、Anthropic公告

为什么重要

这轮变化同时触及单价和重复计算。对于多轮检索、编程与办公代理，缓存命中和重试次数会放大模型价格差异。由此推断，原本需要限制使用频率的任务，可以重新测算经济性；但采购比较必须保持验收标准一致，否则便宜的调用可能被更多失败与人工返工抵消。

接下来观察用固定任务集比较“每项验收通过任务的总费用”，同时记录延迟、缓存命中与人工修订时间；不要用不同厂商的内部测试百分比直接计算性价比排名。

Gemini 扩大应用连接，ChatGPT 把插件带进 Voice，代理入口继续前移

事件2026-09-24 00:00（北京时间），Google 发布新一批 Gemini Connected Apps 公告，开始分批接入 Airtable、Linear、monday.com、Adobe、Webflow、Peloton 等生产力、创作与生活服务。用户可以在设置中连接，也可通过 @ 提及或直接提出请求使用。原文日期为9月23日，官方 RSS 时间为16:00 UTC；这是24日凌晨增量，不是23日白天发布。Google公告

OpenAI 的9月23日独立日志条目则宣布：Voice 在网页、iOS、Android 支持账户可用的插件和连接应用；Work 中可以口述创建文档、演示和表格，结束通话后未完成任务能够继续以文字执行。Free、Go 可使用其套餐支持的 Chat 插件；Voice in Work 需要同时具备相应访问权限。涉及确认的操作仍须在屏幕上批准，口头批准不受支持。产品日志、Voice说明

为什么重要

连接应用扩大了代理能够触及的工作范围，语音则降低发起任务的操作成本。两者结合后，用户更可能直接表达目标，而把切换软件、寻找入口交给助手。对应用厂商而言，竞争开始包含能否被可靠调用；对助手而言，权限确认、执行状态与结果回传将直接影响留存。

接下来观察检查目标账户实际出现了哪些连接器、能执行哪些动作，以及失败后能否恢复。Google 此次公告没有给出完整的地区与套餐清单，不能据“开始推出”推断全球账户均已开放。

豆包工作增加目标、计划与队列，长任务开始有更明确的控制方式

事件快科技9月23日15:52:07的原发报道介绍豆包工作本周升级，并称已向桌面端全量推送：目标模式允许设定验收标准，计划模式先讨论方案、确认后执行；任务队列使新指令在当前任务完成后依次处理。另外增加 Markdown 在线编辑、分享和深色模式。本期依据的是媒体原发报道及其产品展示，尚未取得对应官方版本日志；“持续迭代直至目标达成”属于功能描述，不能当作独立测得的交付保证。原发报道

为什么重要

长任务的摩擦常发生在目标不清、执行过早和追加指令相互打断。把验收条件、计划确认与排队分别做成产品机制，能够减少用户临时接管的负担。这意味着办公代理的竞争不只看一次输出质量，也开始看用户能否持续控制任务方向，以及多个请求是否保持清晰的先后关系。

接下来观察验证计划确认后修改要求是否会重新征求确认、队列是否支持取消，以及目标未达成时是否存在清楚的停止条件与费用边界。报道没有给出这些机制的完整行为规范。

Gemini 3.8 TTS 扩展声音设计与复制，语音生产流程比音色数量更值得看

事件Google 9月23日介绍 Gemini 3.8 Flash TTS 与 Flash-Lite TTS。前者强调可表达性和自然语言声音设计，后者面向高吞吐语音生成；AI Studio 的声音复制流程支持以约30秒录音创建声音，但需要授权及验证录音，并有地区限制。公告同时介绍多说话人、逐行表演指导及内容凭证等能力。API 更新日志已于9月22日记录相关模型 GA，应区分 API 开放与23日产品介绍。产品公告、API日志

声音复制在 AI Studio 的开放范围不包括伊利诺伊州、得克萨斯州、欧洲经济区、英国、瑞士和印度；公告中的部分后续能力仍标为即将推出，不能合并写成全部上线。开放条件

为什么重要

从选择预设音色，走向描述声音、控制表演并在同一流程中修改，减少了配音生产里反复试听和重新录制的环节。对内容、本地化与品牌团队，潜在收益是更低的改稿成本和更一致的声音资产；但真正决定商用价值的仍是长文本稳定性、授权流程和目标市场可用性。

接下来观察比较长篇旁白的跨段一致性、局部修改后声音是否漂移，以及授权校验所需时间。TTS 是语音生成能力，不能直接等同于具备工具执行能力的语音代理。

趋势分析Connecting the Dots
1

模型降价正在改变代理任务的经济性，但节省要以交付验收计算。

Sol/Luna 降价并减少重复上下文处理，Opus 5.5 则直接以典型工作负载成本宣传改进。两条证据共同说明，竞争已经涉及一次完整任务消耗多少计算。本文推断，模型路由可以进一步细分：低复杂度环节优先便宜模型，难点再升级。可验证信号是固定质量门槛下的任务总成本，而非单一输入价格。OpenAI、Anthropic

2

应用接得越多，执行控制越可能成为核心差异。

Gemini 扩展连接器，ChatGPT Voice 把口述请求带进工具执行，豆包工作则把计划确认和指令排队显式化。这些变化分别解决可达范围、输入便利与过程管理。由此推断，下一阶段的体验竞争会集中在中途改需求、取消和恢复，而不只是第一次演示成功。可以用同一跨应用任务，在执行中追加限制，测量错误操作与恢复成本。Gemini、Voice、豆包工作

3

持续服务需要记忆基础设施，也需要清楚的授权边界。

DeepMind 的加密服务器端记忆方案，回答状态如何跨设备保留；Gemini 当天扩展的应用连接，则增加了状态来自何处、能够用于哪些任务的问题。本文推断，个性化不再只是回答风格，而会进入身份、密钥和应用权限设计。判断其成熟度应看具体产品开放、撤销权限后的行为和记忆删除能力；架构公告本身尚不能证明用户体验已经落地。记忆架构、应用连接

4

创作工具的价值正在向可修改、可接续的中间产物移动。

新 TTS 提供声音设计与表演控制，Flow 工具则强调可编辑音轨和可复制工作流。它们共同降低的，是生成结果进入专业生产流程时的修改成本。由此推断，商业化评估应关注一次交付后需要返工多久，而非只展示最漂亮的样例。可验证信号是局部修改是否保留其余质量，以及导出产物能否被现有团队直接接手。TTS、Flow

信源与可信度Sources & Caveats
  • 产品价格、功能和开放条件优先采用厂商原文；官方性能、效率与安全声明不等于独立验证。本文的竞争影响与产品判断均为基于已列事实的分析推断。
  • 豆包工作采用媒体原发报道，未伪装成官方版本公告；Micro1 金额保留匿名消息源和公司未确认的边界。
  • Google 两条凌晨公告用官方 RSS 的带时区时刻确认窗口，文章正文用于核实功能。其他官方日期没有分钟级证据时保留原始日期，不把抓取时间当首发时间。
  • 所附完整 X 记录可支持相应账号在该时刻的陈述；转推残片、用户体验赞语和股价因果说法没有升级为已核实产品事实。近期版本和历史文书均明确标注原始日期。
