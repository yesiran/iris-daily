MiMo-V2.6 同时交付模型、强化学习资源和桌面入口

事件小米官方模型日志将 MiMo-V2.6-Pro、Flash、Pro-UltraSpeed 的发布日明确列为9月22日。三者分别面向复杂任务、高频调用及低延迟场景；UltraSpeed 的“最高20倍推理速度”是官方上限描述，不能理解为所有请求都获得同等加速。模型发布日志

完整公告同时宣布开放模型权重、技术报告、蒸馏模型及7000多个强化学习任务环境，并提供训练框架与可组合的智能体执行框架。MiMo Desktop 和会员方案同步上线，允许订阅使用或自配 API Key；原邀测活动将在一周后结束。官方称 API 延续 V2.5 系列定价。小米公告

为什么重要

应用团队获得了更直接的使用入口，研究团队则获得继续优化任务表现的材料。由此推断，小米争取的不只是模型调用份额，也包括围绕训练环境形成的开发活动。对已有智能体产品，新增机会是把自己的任务验收标准接入改进过程，检验通用能力能否转化为稳定交付。

接下来观察独立团队能否复现训练收益，并在同一业务任务上减少重试与人工接管。桌面客户端不等于旗舰模型可在普通电脑本地运行；模型卡中的权重部署是一套另外的资源要求。官方模型卡

2

GPT-6 Sol、Luna 开始进入 Codex 和 ChatGPT Work

事件OpenAI 9月22日独立更新条目宣布，两款模型向 Codex、ChatGPT Work 逐步开放，token 价格低于各自 GPT-5.6 前代。范围包括 Plus、Pro、Business、Enterprise、Edu；Free、Go 用户可在桌面应用使用 Luna。ChatGPT 内的开放位置是 Work 与 Codex，不包括普通 Chat。官方更新日志

配套费率表显示，在 Standard 速度、按积分计费的口径下，Sol 每百万输入、缓存输入、输出 token 分别为50、5、250积分，对应 GPT-5.6 Sol 为100、10、500积分。这个比较支持同口径费率减半，不代表 API 美元价格或订阅内含额度也按同一比例变化。官方积分费率

为什么重要

新模型直接进入已有任务入口，减少了用户为了尝试新能力而迁移工具的成本。较低费率也给复杂任务与高频任务重新分配模型提供空间。由此推断，团队可以扩大自动化任务量，但需要同时考察交付质量；更便宜的调用若带来更多失败，仍可能增加总成本。

接下来观察企业工作区首发默认关闭，管理员须分别启用 Sol、Luna。应验证实际账号与客户端的可用性，再比较同一任务集的成功率和费用；更改本地模型名称不能越过组织访问控制。企业开放条件

3

Claude Opus 5.5 降低单价，把竞争进一步推向任务总成本

事件Anthropic 官方公告日期为9月22日。Opus 5.5 标准输入、输出价格分别为每百万 token 4美元、20美元，较 Opus 5 下降20%；缓存读取为0.20美元。公司称默认设置下典型工作负载成本下降40%，其中还包含消耗减少，不能把它等同于单价下降40%。发布公告

产品日志另行确认发布，并把“多数工作达到 Fable 5.1 水平”作为公司的能力定位。本期保留官方日期，没有把美国日期转换成一个未经证实的北京时间首发分钟，也不把能力定位当作独立评测结论。Claude 产品日志

为什么重要

长任务会多次读取上下文、调用工具和纠错，因此输入价格只是费用的一部分。若单价和消耗同时下降，旗舰模型就可能进入此前预算不足的常规工作。对产品团队，真正影响默认路由的是每项合格交付的费用，而不是同样数量的 token 便宜了多少。

接下来观察固定任务、工具和推理设置，比较成功率、总费用及人工复核时间。公告中的额度提升与可保留重置有助于尝试新模型，但不能替代长期成本验证。

趋势分析Connecting the Dots
1

模型路由的比较单位正在变成每项合格交付的成本。

OpenAI 降低工作模型费率，Anthropic 同时降低单价并宣称减少任务消耗，给不同复杂度的任务重新分配模型提供条件。由此推断，团队可能在相同预算下增加自动化工作量，但收益取决于质量门槛是否保持。可验证信号是固定任务集的成功率、重试量、总账单和复核时间共同改善；只看输入价格会遗漏失败成本。OpenAI 费率、Anthropic 公告

2

模型开放越来越依赖它进入哪条已有工作流程。

MiMo 同步提供桌面入口，OpenAI 把 Sol、Luna 交付到 Work 与 Codex，并让 Luna 进入部分免费桌面使用范围。两项当日变化都缩短了新模型到用户任务的路径。由此推断，独立应用需要更多依靠专有材料、编辑流程和成果复用保持差异；下一步应观察用户是否持续完成任务，而非只记录新模型尝试量。本期没有市场份额数据来证明迁移已经发生。小米公告、OpenAI 日志

3

能力比较需要把执行条件一起公开。

MiMo 开放训练环境与框架，Anthropic 的当日评测注释披露推理强度和部分安全回退安排。这说明模型分数背后还包含工具、预算及控制机制。对产品决策的推论是，复现必须固定这些条件，才能判断优势是否可以迁移到自己的工作。真正值得追踪的是相同预算与权限下的独立任务成功率；资源开放本身不等于已经实现无人监督的递归自我改进。MiMo 公告、Opus 评测说明
