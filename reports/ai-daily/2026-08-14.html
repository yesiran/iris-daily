DeepSeek 正式发布 V4-Pro，并大幅上调 API 价格——中国大模型"价格战"时代或就此翻篇

DeepSeek 8 月 14 日正式发布旗舰模型 V4-Pro（GA 版本代号 DeepSeek-V4-Pro-0813），主打智能体（agent）能力——工具调用、执行代码、多步骤自动完成任务；同时宣布对 V4-Pro 与 V4-Flash 两档全面提价，并首次引入高峰/低谷分时计价。据 Caixin 财新（8-14） 报道，峰值档相比旧价最高上调可达约 1,100%（缓存命中 0.3 元/百万 tokens、未命中 9 元、输出 27 元，低谷时段减半）；Nikkei（8-14） 称最终定价"比此前预告高出近 5 倍"；Engadget（8-14） 概括为 API 价格约上调 4 倍。

- 为什么重要：DeepSeek 过去的招牌就是"极致便宜"，是把中国乃至全球大模型 API 价格打下来的那条鲇鱼。如今它主动把旗舰价往上抬（尤其把 Pro 定位成"用得起就说明值得付溢价"的高端档），本质是承认：真正强的 agent 模型跑起来算力成本高，靠低价换量的打法撑不住旗舰。

- 意味着什么：这是一次风向标——如果连 DeepSeek 都开始为"能力"收溢价、并用分时计价来平峰填谷（像电价一样管理算力负载），说明中国厂商正从"比谁便宜"转向"比谁能把 agent 能力变现"。同日智谱发 GLM-5.3、阿里预告 Qwen3.8-27B（见下），三巨头一个月内密集迭代，价格与能力同时上探。

2

智谱发布 GLM-5.3：号称"编程能力最强的开源模型"，性能逼近 Fable 5

8 月 14 日，智谱（港股 2513.HK）正式发布新一代基座模型 GLM-5.3，总参数约 7430 亿。关键点：不换基座（与 GLM-5.2 同底），全部提升来自"后训练 Scaling"——用数十倍规模的长程任务环境、更丰富的环境类型、超长后训练时间把模型智能上限往上顶。据 IT之家（8-14） 与 新浪科技（8-14），GLM-5.3 内部体感评测较 5.2 提升约 50%，在 Terminal Bench 3.0、Agents' Last Exam(CLI) 等公开基准上拿到开源第一，编程与智能体能力"接近 Fable 5"；网易/新京报贝壳（8-14） 特别提到其涌现出网络安全能力。开源权重预计发布约两周后（8 月底）放出，需先完成安全评估加固（掘金技术解读，8-14）。

- 为什么重要：GLM-5.3 证明了一件事——不训练新基座、纯靠后训练 Scaling，也能把开源模型的编程/agent 能力推到接近闭源前沿。这对"是不是每次进步都要重新烧一遍预训练"的行业假设是个反例，也降低了追赶前沿的门槛。

- 意味着什么：智谱刚在港股上市（36氪称其为"从清华实验室走出来的千亿科技独角兽"），但发版当天股价却"冰火两重天"下挫（网易，8-14）——技术登顶与资本市场情绪脱节，说明市场对国产大模型"能不能赚到钱"仍高度存疑，跟第 1 条 DeepSeek 涨价其实是同一个焦虑的两面。

3

Anthropic 给所有 Claude 输出加"隐形水印"，并把 Claude Code 默认切到 Auto Mode

8 月 14 日 Anthropic 宣布：Claude 生成的所有文本与代码，都会在模型层嵌入机器可读的隐形水印，复制粘贴后仍会跟随、部分编辑后仍可能留存，目的直指欧盟《AI 法案》对 AI 生成内容标注的要求（The Hindu，8-14、Geeky Gadgets，8-14）。同日，Anthropic 把 Claude Code 的默认权限模式改为 "Auto Mode"（Pro/Max/Team 新会话默认自动放行工具调用，用分类器实时筛查风险动作，取代逐条人工确认）（Developments Today，8-14）。

- 为什么重要：这是头部前沿实验室里较早把"内容溯源"做进模型底层的动作——合规从"外挂检测"变成"产品自带属性"。同时 Auto Mode 默认化意味着"让 agent 自己跑、别老打断"正在成为行业默认姿态。

- 意味着什么：水印引发了版权/隐私争议（"人写的到哪一步算 AI 写的"），Anthropic 当天还专门澄清（Digital Today，8-14）。一边是监管倒逼透明，一边是产品放手让 agent 自主执行——"可追溯"与"更自动"这两股力量同时加速，是接下来最值得盯的张力。

4

谷歌上线 Gemini 3.7 Flash：更便宜的编程/智能体"主力马"，恰逢 DeepMind 大重组

8 月 14 日，Google DeepMind 推出面向编程与 agent 任务的 Gemini 3.7 Flash，距上一版 3.6 Flash 仅约三周；皮查伊称其为"以极高性价比提供性能的主力马（workhorse）"（explainX，8-14、Cryptonomist，8-14）。背景是谷歌刚宣布 DeepMind 史上最大规模的组织重组（原始日期 8-13）：CTO/首席 AI 架构师 Koray Kavukcuoglu 升任 GDM 高级副总裁，统管 Gemini 模型研发、前沿研究与 Gemini App/开发者团队（Google 官方博客，8-13），外界解读为谷歌"收紧对 DeepMind 的控制、集中火力追赶 OpenAI 和 Anthropic"（Seoul Economic，8-13/14）。

- 为什么重要：Flash 这条"便宜快"线三周一迭代，直接压向 DeepSeek/智谱/OpenAI 的中小档位；而它落地的时点，正卡在谷歌用组织手术"逼 DeepMind 全力押 Gemini"之后。

- 意味着什么：模型迭代节奏正被组织意志和竞争焦虑推着走——产品发版和权力重组是同一件事的两面：谷歌承认自己落后，于是用更快的低价迭代 + 更集权的研发指挥来抢时间。

5

苹果为中国市场自研大模型，由阿里巴巴协助——首家获北京批准提供自有 AI 模型的外企

据 路透社独家（8-14），苹果没有沿用第三方模型，而是为中国市场训练了自己的大语言模型，并在阿里巴巴协助下落地 Apple Intelligence。The Next Web（8-14） 称苹果是首家获北京批准、在中国大陆提供自有专有 AI 模型的外国公司；Benzinga（8-14） 指其意在对抗华为、扳回中国市场。

- 为什么重要：中国对算法/大模型审批一向严格，"外企自有模型获批上架"是罕见口子；而苹果选择自研+阿里做本地合规与基建伙伴，是一条"既要合规、又不想把大脑完全交给别人"的折中路线。

- 意味着什么：这既是苹果中国 AI 战略的关键落子，也让阿里成为外企进入中国 AI 市场的"守门人+基建方"——地缘政治、监管与商业绑定在同一笔交易里。
