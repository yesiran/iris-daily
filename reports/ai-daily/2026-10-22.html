截至 2026-10-23 02:00（北京时间）。本期覆盖10月22日全天及23日凌晨截稿前增量：主线是智能体从回答问题走向持续工作，竞争随之转向企业分发、执行控制和可靠交付。

要闻速览：Duet 主动工作；Uber 扩大部署；Security 持续修复；Minerva 算力运维。

一、今日要闻

1. Claude Duet 开放候补预览，主动服务开始消耗真实工作额度

事件：Anthropic 官方10月21日发布 Claude Duet。预览从美国 Pro、Max 用户的候补名单开始，通过独立移动应用和网页提供服务。它在云端继续工作；后台每隔数小时检查连接账户，发送消息、付款、签署文件或删除内容前须获用户批准。后台检查与任务共享 Claude 套餐额度，并非新增无限用量。官方公告

为什么重要：主动检查减少了用户自己发现待办的负担。它把“发现遗漏”纳入产品价值，也把注意力判断和后台成本变成日常体验的一部分。对办公助手而言，竞争重点将从生成一份漂亮答案，移到能否少打扰用户、及时发现问题，并在既定预算内完成后续工作。

接下来观察：候补用户实际获得访问后，每周有多少后台提醒被采纳、每件完成任务消耗多少额度。预览版可能误判紧急程度，且暂不能展示浏览器，这会影响纠错。

2. Uber 将 ChatGPT Work 从千人试点扩展至全公司，分发与复用成为部署重点

事件：OpenAI 10月22日公告，Uber 启动面向全球超过3万名员工的 ChatGPT Work 推广，起点是此前1000人的试点。配套包括内部技能库、获批的应用集成及员工培训；成效尚待披露。部署公告

近期背景：10月21日，OpenAI 与 Google Cloud 宣布将前沿模型及 Codex 工作流引入 Model Garden，可抵扣客户已有 GCP 消费承诺；全面开放计划在未来数周，不是当天全部可买。10月22日的 FDE 文章则披露一个客户案例：转到共同的 Codex 基础后，团队去掉约90%的定制代码。这是厂商案例，不能外推为所有企业的收益。云合作；工程案例

为什么重要：企业接入智能体的障碍不只在模型效果，还在采购、授权和每个部门重复集成。现有云预算降低采购摩擦，共同技能与运行基础降低复制成本。推论是，拥有分发渠道和组织内复用能力的平台，会更容易扩大部署；但部署人数不能替代任务完成率和经济回报。

接下来观察：Uber 承诺后续披露的采用率与可衡量成效，以及 Google Cloud 的实际开放日期、区域和模型清单。

3. Claude Security 加入持续扫描、修复追踪和 API，安全工具开始负责后续工作

事件：近期进展，官方日期10月21日：Claude Security 面向 Claude Enterprise 客户开放新版公测，仓库代码变化后可持续扫描，修复落地后自动标记已解决，再次出现则重新打开。它增加项目知识库、可编辑威胁模型、API、Webhook 和 MCP 接入，以及分角色权限；能力不以取得 Cyber Verification Program 资格为前提。产品公告

持续重要的背景是漏洞响应链：OpenAI 同日披露，与维护者和安全机构协调修补 PHP 严重漏洞，Calif 使用 GPT-5.6 Sol 参与发现，Wiz 也独立发现并报告。协同披露

为什么重要：一次扫描只能交付问题列表，代码变化会让结果失效。持续检测、核对修复和把结果送入现有开发工具，才把发现变成可管理的工作队列。评估单位由“找出多少漏洞”转为“多少高风险问题被正确修复且不复发”；这也改变了安全产品与编码智能体的集成优先级。

接下来观察：在真实仓库中，误报经团队补充环境知识后是否减少，以及已解决问题重新出现时能否准确重开。

4. NVIDIA 推出 Minerva，把算力运维目标转向有效产出

事件：NVIDIA 10月22日发布 Minerva，将 GPU、网络、存储、调度器及工作负载遥测关联为动态知识图谱，识别异常、追溯可能根因，并提供自然语言助手与外部自动化接口。官方称 IREN 已在使用，IBM、Lambda、Tesla 等计划部署；未公布经独立验证的平均停机降幅。Minerva 公告

为什么重要：大集群中一个退化组件就可能拖慢整项任务，添购 GPU 未必同比增加交付。把设备状态与作业表现连接起来，才能识别哪些故障在吞掉有效算力。推论是，云服务的竞争会更多落在可持续产出的 token、任务完成时延和恢复速度上，运维软件也因此进入推理成本的核心位置。

接下来观察：合作方的有效吞吐、故障间隔和平均恢复时间是否改善，以及自动修复需要何种人工介入。

四、趋势分析

1. 主动智能体的核心成本是“何时值得工作”。 Duet 的后台检查计入额度，Gemini 则把任务集中到小企业营销、财务与品牌场景。两者共同指向：产品必须证明后台行动比额外推理和用户打扰更有价值。可验证信号是每次主动建议带来的实际完成任务，而非通知量。Duet；Gemini

2. 企业竞争正在进入组织流程与采购预算。 Uber 的全员部署与 Google Cloud 的采购安排，分别解决组织扩散和预算接入；FDE 案例说明共同运行基础可减少重复代码。推论是，产品总监需要同时评估部门复用与权限管理，否则模型改善仍会被部署摩擦吞掉。验证点是第二个团队上线所需时间及后续维护负担。部署；工程案例

3. 有效算力与完整服务能力比峰值吞吐更接近商业成本。 Minerva 处理设备退化造成的产出损失，DeepInfer 则揭示高效内核之外仍有缓存和调度工程。采购推理服务应比较达到同一成功率与时延目标的总成本；硬件利用率高、离线吞吐高，都不自动保证线上工作流更便宜。Minerva；DeepInfer

4. AI 研究交付开始围绕“下一步决策”组织。 ForTy 输出类别概率和变化序列，Rosalind 输出待实验验证的机制假说；前者帮助决定哪里需要审查，后者帮助决定先做什么实验。推论是，垂直产品的机会在证据组织、置信度与验证接口，而非把研究结果包装成确定答案。信号是下游专家是否据此改变工作排序并得到可重复收益。ForTy；Rosalind
