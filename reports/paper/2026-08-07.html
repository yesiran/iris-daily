推荐理由

今天选它，不是因为票数（HF 8-7 新榜刚开，它 37 赞、排三四位，还在涨），而是因为三件事叠在一起：

  1. 它推进的是"机理"，不是刷分。它问的是一个所有前沿模型都绕不开、但一直靠拍脑袋试错的问题：把"看懂图 / 画出图 / 会说话"这三种本事从头塞进同一个模型里一起训，它们到底是互相帮、还是互相抢？该先训哪个？结构该共享到什么程度？这篇像做物理实验一样，把每个旋钮单独拧、量因果，第一次给出了可复现的定律——这正是本 skill 要追的"揭示模型内在机理"。
  2. 机构信号顶配。作者是 Meta FAIR × NYU × 牛津的一线班底：Mike Lewis（BART / Llama 作者）、Rob Fergus、Naila Murray、Philip Torr、Peter Tong（Cambrian-1 作者）。而且它是这个组自己 3 月《Beyond Language Modeling》的机理化续作——从"探索出一些现象"升级到"总结成物理定律"，脉络清清楚楚。
  3. 方向就是模型进化的主线。前沿正在从"给语言模型外挂一个视觉眼睛"整体转向"一个模型从头一起长出所有模态"（GPT、Gemini 都在这条线上）。这篇是给这个转向补上"到底该怎么训"的科学地基。

诚实交底：它今天在 HF 榜上不是第一（第一是一篇 agent 训练法 ABSeeker），最近半个月 ledger 里 agent / 强化学习也已经很密。我特意换一个完全不同的前沿切面给思染——多模态到底怎么"发育"出来的。信号偏"机构+机理"而非"票数",这点如实说明。

七拍故事

1. 主角

一个想同时看懂图、画出图、还会说话的模型——也就是今天所有前沿大模型都在往里走的"原生多模态"（native multimodal：不是外挂一个视觉模块，而是一个模型从头把文字、看图、画图一起学）。

以及一群想把这件事从玄学变成科学的研究者：Meta FAIR、纽约大学、牛津的一线团队。他们的口号很直白——给多模态预训练找出它的"物理定律"。

2. 困境

大家都在抢着做原生多模态，但没人真说得清这三种本事塞进一个脑子里会发生什么。撞的是三面墙：

  • 加视觉数据，会不会把语言能力拖垮？ 一个模型容量就那么大，让它花力气学看图，会不会把说话的本事挤没了？
  • 该先训哪个？ 是先把语言模型训扎实、再"接上"视觉省事？还是一开始就一起训？
  • 结构该共享到什么程度？ 注意力、前馈网络、归一化——哪些该让文字和图像共用一套、哪些该各走各的？

解不了这三面墙，就只能烧钱试错：训一版、发现不对、推倒重来。多模态预训练一次实验动辄几千张卡几周，试错代价高到离谱。

术语落地：前馈网络（FFN, Feed-Forward Network）——每个词（或每个图像块）过完"注意力"这一步之后，还要各自单独过的一个小型两层神经网络。可以理解成模型里负责"加工、存知识"的车间。归一化（normalization）——把一层的数值缩放到一个稳定范围，防止训练时数值乱飘，相当于每层之间的"稳压器"。

3. 旧路

之前主流两条路，都没有"定律"，全凭手感：

  • 后接派（late alignment）：先把一个纯语言模型训好，再把视觉"对齐/接"上去。省事、复用现成语言模型。业界大量做法是这样。（剧透：这篇发现它有隐性大代价。）
  • 凭直觉设计结构派拍脑袋决定哪些结构共享、哪些分开，训出来能用就行，说不清为什么。

而这个团队自己 3 月的《Beyond Language Modeling》（arXiv 2603.03276）是"探索版"——试出了一些"统一多模态预训练有戏"的现象，但还没上升成规律。这篇要做的，就是把它变成"物理"：受控实验、单变量、可复现的定律。

4. 转折

关键的一转念：别再拿"能不能 work"当问题。改成像物理学家做实验那样——把每一个旋钮（语言数据配比、视觉数据配比、生成数据配比、接入的早晚、结构共享的程度、视觉数据的复杂度）单独拧一格，然后精确测量：它对另外两种能力产生了什么因果影响？

于是"多模态"这团糨糊，被拆成了一张有方向、有强弱、有临界点的力场图。哪股力帮哪股、帮多少、什么时候会翻脸变成互相抢——都能量出来。

5. 解法：四条定律（术语全部落地）

他们先在小规模上单变量地扫，测三种能力：

  • 语言9 个多选推理/常识题 + 两个问答基准（Natural Questions、TriviaQA）+ 在 DCLM/C4 上的"困惑度"。
  • 视觉理解16 个基准，分四类——通用（GQA/MME/MMBench/SEED）、知识（ScienceQA/MMMU/MathVista）、OCR 与图表（TextVQA/ChartQA/DocVQA/OCRBench）、纯视觉（RealWorldQA/MMVP/CV-Bench）。
  • 视觉生成GenEval（能不能按提示把元素正确组合出来）、DPG-Bench、CLIP 相似度、生成的扩散损失。

术语落地：困惑度（perplexity, ppl）——模型对"下一个词"有多"意外"。越低说明它越笃定、预测越准，是语言能力最基础的体温计。扩散损失（diffusion loss）——衡量模型"画图"这一步画得准不准的误差，越低越好。

扫出来四条定律：

定律一 · 知识流动（谁给谁当养料，而且不对称）

  • 语言 → 视觉：强正向。 把训练数据里语言的比例从 0% 一路加到 80%，视觉理解全线单调变好。⚠️ 这条最反直觉：多喂纯文字，反而让模型更会看图。 语言像是视觉理解的养料。
  • 视觉理解 → 视觉生成：强正向。 多喂"看懂图"的数据，"画图"明显变好，扩散损失显著下降。会看，才会画。
  • 视觉生成 → 语言/理解：基本中性。 加生成数据，对另外两样既不明显帮、也不明显拖（语言分数只有小幅波动）。
  • 他们还用 CLEVR（一个可控的合成图像集）把迁移精确到概念级：颜色、形状这种低层属性在两个方向上都几乎零迁移；空间关系、大小、数量这种结构性概念则是不对称的——"理解"能把它迁给"生成"，反过来"生成"几乎迁不回"理解"。

一句话内核能力之间不是平等互换，而是有方向的养料流，且这条流是偏的。

定律二 · 协同还是竞争，由"数据复杂度"决定

同样是加视觉数据，是帮忙还是抢地盘，取决于图有多"难"：

  • 简单视觉（纯色背景、噪声图）是"跨模态助推器"——加进去，连语言困惑度都还降了（Δppl −0.211、−0.183，负号=变好）。
  • 复杂视觉（视频、SSTK 这类）会抢容量、逼出竞争——语言困惑度不降反涨（Δppl +0.052、+0.075，正号=变差）。

结构配方（怎么让它们协同而不是打架）

  • 共享注意力 + 共享最后一层归一化 → 给不同模态留一条"能互相对话"的通道。
  • 分开前馈网络（论文叫 split_ffn）→ 让每种模态有自己的加工车间，不互相抢容量。
  • 效果对比很硬：split_ffn 同时拿到语言 +0.211、视觉 loss −0.0168 的协同；而全共享的 dense（连前馈也共用）两头亏——语言 −0.272、生成 +0.0537（都变差）。这个结论在 4 种不同的视觉编码器上都成立（RAE、原始像素、CLIP+VAE、UniTok/AR），不是某一种搭配的偶然。

一句话内核要多能力共处，秘诀是"共享对话通道、分开加工车间"。

定律三 · 越早一起长越好 + "视觉偷懒"现象（vision laziness）

固定总训练预算，只改视觉数据接入的早晚：先纯语言训 0 / 200 / 400 / 600 / 800B（十亿）个词，再接视觉。结果——接得越晚，最终越差，通用/OCR/纯视觉理解和所有生成指标一路下滑。再把六种"先后顺序"方案全试一遍，"一起从头联合训"碾压所有先后方案；连最像人类发育的"先看世界→再学理解→最后学说话"都不如联合训。数据回放（replay）能缓一点"学新忘旧"，但补不回损失掉的协同。

为什么？他们抓到了机理，取名 vision laziness（视觉偷懒）：视觉接得越晚，视觉通路就越"不肯投入自己"，实测四个信号同时变弱——

  • 视觉专用前馈的激活强度越来越"安静"；
  • 包裹图像的特殊 token 的向量越缩越小（越没融进语言的"意义空间"）；
  • 推理时视觉前馈的激活骤降；
  • 生成时"图像块去看其它图像块"的注意力占比明显下滑。

说人话你先让模型把语言练得特别强，再塞视觉进去，它会发现"靠语言先验猜一猜"比"老老实实去看图"更省劲，于是学会走语言捷径、偷懒不真看图。你给它留了条省力的路，它就不走难而对的那条了。

定律四 · 配方（把前三条落成省算力的实操）

把三条定律拼成配方：非对称数据配比（按定律一，语言多喂点去养视觉）+ split_ffn 结构（按定律二）+ 早期联合训（按定律三）。结果：只用 5% 的算力预算就拿到很强的生成性能。然后在多个 13.5B（135 亿参数）的 MoE 模型、2T（2 万亿）token 上做单变量对照，把这套配方在大规模上验证站得住（默认结构：16 层、隐藏维 2048、分组查询注意力 GQA 32 查询头/8 键值头、前馈放大 1.5 倍）。

术语落地：MoE（Mixture-of-Experts，混合专家）——模型里放很多个"专家小网络"，每个 token 只激活其中一小撮，用小得多的计算量撑起大得多的参数量。token——模型处理文本/图像时切成的最小单位（一个词、词的一部分、或一个图像块）。

6. 结局：世界变了什么（含最反直觉的副发现）

多模态预训练第一次有了可复现的"物理"：能预测三种能力互相怎么影响、能省 95% 的试错算力（只花 5%）、还能解释为什么。三个最反直觉的副发现，值得单独记住：

  1. 多喂纯文字，反而让模型更会看图。 语言是视觉理解的养料——最"省事"的那条路（后接视觉）恰恰不是最好的。
  2. "先练好语言再接视觉"这条业界最省事的主流路，会让模型偷懒不看图。 省事的代价是能力打折，而且是隐性的、不测激活根本发现不了。
  3. "越像人类发育越好"是错的。 人是先看世界后学说话，但模型一起从头联合训才最好——生物直觉在这里帮倒忙。

7. 内核（走出门带走的那颗种子）

把多种能力塞进一个模型，不是"拼装"，是"共同发育"。 谁给谁当养料是有方向、不对称的（语言喂视觉、理解喂生成）；越早一起长越好，晚接的能力会"偷懒"不投入；要让它们协同而不是互相抢，靠的是"共享对话通道、分开加工车间"。

来龙去脉（倒读溯源 · 3 层）

  • 第 1 层（直接前作）这篇续自同一个团队 2026 年 3 月的《Beyond Language Modeling: An Exploration of Multimodal Pretraining》（arXiv 2603.03276）。前作是探索——试出"统一多模态预训练有戏"的一批现象；这篇是把它机理化/物理化——受控单变量实验、总结成可复现定律。名字从"Exploration（探索）"到"Physics（物理）"，就是这一步升级。
  • 第 2 层（能力根基）再往上是 Cambrian-1（Tong 等 2024，把"视觉理解"这件事在多模态大模型里做扎实的代表作，本篇一作 Peter Tong 也是它的作者）和 Web-SSL（Fan 等 2025，大规模视觉自监督预训练）。这条线解决的是"怎么让模型真看懂图"。本篇的视觉理解评测协议，直接沿用了 Cambrian-1 这一脉。
  • 第 3 层（时代背景 / 被它补课的对象）：更大的背景是整个前沿的"原生多模态"转向——从"给语言模型外挂一个视觉编码器、最后拼一下"（late fusion / 后接）走向"一个模型从头一起学所有模态"。GPT、Gemini 都在这条线上。这篇正是给这个转向补上"到底该怎么训"的科学地基，并用 vision laziness 把它要取代的那条老路（后接视觉）的隐性代价第一次量化出来。

对思染：模型进化 & 怎么用

这一步，模型进化往哪挪了

前沿正从"文本模型 + 外挂视觉眼睛"整体切换到"原生一起发育的多模态"。这篇最大的意义，是把这个切换从"工程玄学"变成"有定律的科学"，并且给出一个反直觉的世界观：模型里的各种能力之间是"发育"关系，不是"模块拼装"关系——有养料流向、有早晚窗口、会偷懒、会抢容量。理解模型往哪进化，就要理解"能力之间怎么互相塑造"，这篇是这方面第一张靠谱的地图。

怎么用（提示词 + 京小贝产品判断）

  1. "偷懒定律"是最通用、最能直接用的一条。 它的本质是：只要给模型一条更省力的捷径，它就会放弃更难但更对的那条路。 这正是提示词工程里"给了参考答案/太强的先验，模型就懒得真推理"的多模态版。落到京小贝：如果你在上下文里塞进现成结论、或一段过强的检索摘要，模型很可能"懒得"再去核对底层数据、直接顺着先验走。对策——用结构强制它 engage 难信号，比如要求"先逐条复述关键数据/字段，再下判断"，把偷懒的捷径堵上。
  1. "早合 vs 后接"迁移到"检索融合 / 上下文注入"。 论文说视觉越早、越深地融进训练越好，最后拼一下（late alignment）最差。对应到 RAG/多源信息编排：把外部信息早早地、深度地编进模型的推理过程（例如在系统层就给角色、给判断标准、给数据口径），通常比"最后临时拼一段 context"更稳。这是一条能直接指导上下文结构设计的直觉。
  1. "共享对话通道、分开加工车间"是多能力共存的结构直觉。 迁到多智能体/多技能编排：让不同角色/技能共享同一份上下文和同一套判断标准（共享注意力/归一化的类比），但各自有专用的处理段/工具（分开前馈的类比），避免它们互相抢"注意力预算"、把彼此的输出搅浑。京小贝里"财富判断 / 事实查询 / 交易执行"这些不同职能，就适合共享事实底座、分开各自的处理逻辑。
  1. "养料不对称"提醒：别想当然地假设"加一种能力/数据会对称受益"。 他们发现语言强喂视觉、生成却不反哺。做数据配比、能力叠加、或给模型加新技能时，要按方向分别验证收益，而不是默认"互相都有好处"。这对做产品能力叠加时的资源分配是个务实的清醒剂。
