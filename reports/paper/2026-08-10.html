推荐理由

今天这篇 EnvACE，讲的是训练"会用工具办事的智能体"时那个最贵、最卡脖子的东西——环境——怎么被彻底绕过去。

先说清楚"环境"是什么：你想让模型学会连着调好几步工具把一件事办成（查天气→订机票→填表→付款），它每调一次工具，总得有个东西"回它一句结果"，它才知道下一步该干嘛。这个"回结果的东西"就是环境：可能是真实的 API、一个模拟器、或工程师手搭的假沙盒。问题是——这个环境本身极贵：真 API 调不起也不敢乱调，假沙盒要一个个手写、还得保证它回的结果是对的（否则模型学到一堆错的因果）。今天整个"智能体强化学习"这行的主流打法，就是拼命造更多、更真的环境去喂模型。

EnvACE 反过来问：能不能不造环境，让模型把环境"背"进自己脑子里？ 它的办法叫"世界排练"——让同一个模型自己跟自己演：一会儿当演员（发出工具调用），一会儿当世界（编出这次调用应该回什么结果），两个角色轮流演、一起变强。练到最后，模型自己脑子里就长出了一个"我这么一动、世界会怎么回应"的预测器，再也不用真环境。

为什么今天选它：(1) 它推进的是一条"scaling 路径"的认知——不是把已有能力调好一点，而是把"训练信号从哪来"这件根本事换了个来源，是 Dreamer 那一脉"基于模型的强化学习"第一次干净地落到 LLM 工具智能体上；(2) 信号中等偏上——HuggingFace 当日榜 #6、38 赞，作者是上海交大张伟楠组（做强化学习/世界模型的知名团队）联手腾讯等七家机构，底座是真训的 Qwen3-8B，不是玩具；(3) 对思染是正中靶心——京小贝要训"会用金融工具的智能体"，最大的工程成本恰恰就是搭一套忠实、安全的 API 沙盒，这篇给的是"让模型自己当沙盒、还能先在脑子里彩排一遍再碰真接口"的思路。诚实说一句：它的绝对分数不是碾压式 SOTA（多数榜单是"打平或略胜"造环境的对手），真正的赢点在范式的省与可扩展——用 8B 打平甚至反超要靠外部环境的更大模型，且不花一分钱环境成本。方向比分数重要，这也是它当选的理由。

七拍故事

① 主角

一个 8B 大小的语言模型（Qwen3-8B），被要求学会一件难事：连着调好几步工具、把一个多轮任务办成——查资料、调 API、看返回、再决定下一步，直到任务完成。

② 困境

要教它这个，标准做法是强化学习：让它去"试错"——真的动手调工具，办成了给奖励，办砸了不给，模型据此调整。可"试错"必须有个对象：它每调一次工具，得有东西回它一句真实的结果。这个"回结果的对象"就是环境。

麻烦在于，环境又贵又难又不可信：

  • 真环境（真实 API）：调用要花钱、有速率限制、还有副作用（真订了机票、真扣了钱），训练时根本不敢让它乱试上百万次。
  • 模拟/合成环境（工程师手搭的假沙盒）：得一个任务一个任务地手写，覆盖不全；更命的是——你怎么保证这个假环境回的结果是对的？ 假环境一旦回错，模型就把错的因果学进去了（这在原文里叫环境要"构造、验证、正确落地"三重成本）。

一句话：在智能体这行，卡脖子的不是"模型学得快不快"，而是"你能不能造出足够多、足够真的环境让它去练"。 环境成了天花板。

③ 旧路

过去大家怎么解？两条路，都在"环境"这个字上打转：

  • 第一条：拼命把环境造大造真。 代表是"Agent World Model / 无限合成环境"这类工作——用代码加数据库搭出成千上万个可靠的假环境，让模型有海量地方练。思路是"环境不够就多造环境"。本篇里的对手 EnvScaler、ScaleEnv、AWM、Simulator 全是这一派。问题没解决，只是把成本堆上去了。
  • 第二条：从已有的交互里榨出更多信息。 代表是它的直接前辈 EnvRL（2606.17680，两个月前）——它发现模型每次真去环境里跑一趟，那条轨迹里其实藏着大量"我一动、环境怎么变"的规律，而稀疏奖励的强化学习把这些规律浪费了。于是 EnvRL 加了两个副任务（预测下一状态、反推刚才的动作），逼模型顺手把环境的变化规律学进去。但 EnvRL 还是得先有真环境、真去里面跑一遍，它只是"从真跑里多学一点"，没把真环境省掉。

④ 转折

作者的关键一转是：既然目标是"让模型脑子里有一个环境模型"，那为什么不干脆让模型自己把环境也演出来？

把两件本来分开的事——"模型（演员）"和"环境（世界）"——合并成同一个脑子的两个角色。模型一会儿演演员、发出工具调用；一会儿演世界、编出"这个调用应该回什么结果"。它自己跟自己演一整场，中间完全不碰真环境。真环境只在偶尔需要时用来对答案、纠偏。这就把"环境"从一个必须外部构造的东西，变成了模型自己脑子里可以生成的能力。

⑤ 解法

这套机制叫 World Rehearsal（世界排练），核心是一个"自我对弈"的循环——自我对弈就是一个模型自己跟自己下棋、两边都是它，越打越强（AlphaGo 那套的味道）。这里两个角色是：

  • 演员角色（Acting）给它当前的历史，让它发出下一个动作（工具调用）。原文写成 a_t ~ π_θ(·|h_t, Act)——读作"在历史 h_t 下、以演员身份，采样出动作 a_t"。
  • 世界角色（Rehearse）把演员刚发的动作接过来，让同一个模型编出"这个动作应该得到什么环境返回"。写成 ô_t ~ π_θ(·|h_t, a_t, Rehearse)——那个带帽子的 ô_t 就是"模型脑补出来的环境回应"。
  • 然后把这一来一回拼进历史 h_{t+1} = h_t ⊕ (a_t, ô_t)，继续下一轮。

最关键的设计这两个角色共用同一套参数 θ（同一个脑子），一起更新。更新用的是 Role-wise GRPO。GRPO 我给你落地一下：它是一种给强化学习省钱算"这步答得好不好"的办法——同一道题让模型答很多遍，把每一遍的得分跟这一批的平均分比，高于平均就往这个方向多推、低于就压回来，好处是不用另外再训一个"裁判网络"去打分（省一大笔）。EnvACE 的"Role-wise"就是给演员和世界各算各的平均基线，免得两个角色互相干扰。

练完之后还有一手测试时排练（test-time rehearsal）：真办任务前，模型先在自己脑子里的世界模型里把好几条候选路线各彩排一遍、挑出最好的一条，再去碰真环境。相当于"三思而后行"——但这个"思"是在自己内化的世界里真跑了一遍，不是空想。

⑥ 结局

用 8B 的 Qwen3 训出来，在四张"会不会连着调工具办事"的考卷上（BFCL-v4、τ²-Bench、VitaBench、FinMCP-Bench，都是专门考多步工具使用的 benchmark）：

  • 总分（四榜算术平均）32.91%，略胜要靠外部环境的最强对手 AWM-14B 的 32.54%——注意 EnvACE 只有 8B，对手是 14B，用更小的模型、零环境成本，打平甚至反超。
  • τ²-Bench 上 36.7%，把 AWM-14B（30.7%）甩开近 6 个点，是赢得最漂亮的一张榜。
  • BFCL-v4 上 46.04%，略输给造环境派 EnvScaler-8B 的 47.07%——这里诚实标注：它没全赢，在这张榜上稍逊，但代价是对手要真造一堆环境。
  • 金融工具榜 FinMCP-Bench工具精确率 54.04%、工具 F1 46.78% 都是全场最高（不过工具召回率 41.23% 输给 EnvScaler 的 49.35%）。
  • 测试时排练白赚一截只彩排 2 条路（N=2、并行挑最优），总分从 36.7% 抬到 40.9%（+4.2），τ²-Bench 从 31.4% 抬到 38.0%（+6.6）。不用重新训练，纯靠"先在脑子里跑一遍再动手"就涨。

最反直觉的两个副发现（最有意思的地方）：

  1. 让同一个脑子既当演员又当世界，比拆成两个专门的脑子更好。 直觉上你会觉得"术业有专攻"，演员归演员、世界归世界，各训各的应该更强。结果相反：参数共享（一套参数干两件事）36.7%，分开训只有 35.5%，共享反而高 1.2 个点。原因很朴素——你越会预测世界会怎么回应，你就越会行动；你越会行动，就越懂世界的脾气。两件事本来就是一体两面，硬拆开反而互相断了养分。这其实是"内化环境能直接帮到策略本身"的证据。
  2. 测试时的"三思而后行"，只对已经内化了世界的模型有用。 拿一个没经过 EnvACE 训练的原始模型去做同样的"脑内彩排"，在顺序模式下反而比不排练还差。也就是说——光多想没用，你得先真把世界的规律学进脑子，"想"才有东西可想。这一刀砍掉了"测试时多花算力就一定更好"的幻觉：多花的算力必须落在一个内化了世界的模型上才生效。

（另外训练动态上有个小坑：中途某些检查点性能会抖动、掉下去，但后期会自己恢复——这种"演员和世界共同进化"的过程会经历一段别扭期。）

⑦ 内核

把"环境"从模型外部一个必须花大价钱构造的东西，变成模型内部可以自己生成的一种能力。 智能体不再只是"世界里的一个演员"，它同时把"世界会怎么回应我"背进了自己的权重里——于是它能在无人陪练、零真实调用的情况下自己排练成长，还能在真正动手前先在脑内彩排一遍。这是"基于模型的强化学习"（先学个世界模型、再在想象里练）这条老思路，第一次干净地落到 LLM 工具智能体身上。

来龙去脉（倒读三层）

第一层——它在超越谁：造环境派（environment scaling）。 当下智能体强化学习的主流共识是"要练得好，就得有更多更真的环境"。于是一整派工作在拼命造环境：Agent World Model（无限合成环境，用代码+数据库搭出海量可靠假沙盒）、EnvScaler、ScaleEnv、Simulator、TOUCAN……它们都把环境当成一个"你必须在模型外面构造出来的外部神谕"。EnvACE 的正面departure：别造了，把环境内化进模型自己。本篇的所有基线都来自这一派，赢它们的意义就是"证明不造环境也能打平"。

第二层——它的直接前辈：EnvRL（2606.17680，2026-06）。 EnvRL 是第一个说"模型真去环境里跑一趟留下的轨迹里，藏着大量被稀疏奖励浪费掉的环境规律"，于是加了两个副任务（预测下一状态、反推动作）逼模型把环境的变化规律学进去。它已经有了"让模型内化环境"的种子。但它还差一步：EnvRL 仍然离不开真环境、必须真去里面跑。EnvACE 把这最后一步跨过去了——让模型自己生成环境回应（自我对弈），于是连真环境都不用了。这条问题线的演化很清楚：造更多环境（第一层）→ 从跑真环境里多学环境规律（EnvRL）→ 干脆让模型自己演环境、不跑真环境（EnvACE）。一步步把"对外部环境的依赖"削到零。

第三层——它的思想根系：Dreamer 那一脉"基于模型的强化学习" + 自我对弈。 更深的根在经典强化学习里：Dreamer/PlaNet 那条线很早就提出——别老让智能体在真实世界里试错（太慢太贵），先学一个"世界模型"，然后让它在这个模型里"做梦/想象"着练，成本极低。EnvACE 本质就是把这套"先学世界、再在想象里练"搬到 LLM 工具智能体上，只不过这里的"世界"是工具生态、API 的行为规律。再叠一层自我对弈（AlphaGo：一个网络自己跟自己下、两边都是它、越打越强）——EnvACE 让同一个模型既是演员又是世界，本质是"跟自己对弈"来同时长出策略和世界模型。所以这篇不是凭空冒出来的新招，而是两条硬核老传统（世界模型 + 自我对弈）在 LLM 智能体这个新场景的合流。 认清这一点，你就知道它大概率不是孤篇，而是一条会持续长下去的主干。

对思染：模型进化 & 怎么用

这一步往哪进化了。 前沿的移动方向是：从"scale 环境"转向"内化环境"。过去一年智能体能力的瓶颈，肉眼可见地卡在"环境不够、造环境太贵"上——所有人都知道智能体要靠强化学习练，可强化学习要环境，环境要人造。EnvACE 代表的转向，跟当年经典强化学习从"在真实世界里试错"跳到"在学好的世界模型里做梦"（Dreamer）是同一种认知跃迁，现在轮到 LLM 智能体了。你要盯的信号：接下来会不会有一批工作沿着"模型自己当环境/自己造训练数据/自己给自己出题"这条线往前走——这是"智能体自给自足、摆脱对外部人造环境依赖"的大方向，一旦成立，智能体训练的成本结构会被重写。

对京小贝的产品判断，三个具体启发：

  1. 训练成本的账要重算。 你们要训"会用金融工具的智能体"，过去的思维定式是"先花大力气搭一套忠实、安全的 API 沙盒"——这套沙盒又贵、又难保证忠实（回错一次，模型学一堆错因果）。EnvACE 给的信号是：模型可以学着自己当沙盒，把你们工具/接口的行为规律内化进权重。这不一定马上能替掉真沙盒，但它改变了"必须先造环境才能训"的前提——沙盒可以从"必需品"降级为"偶尔用来对答案的校准器"。
  1. "测试时排练"是一个可以马上偷来用的产品/提示词模式。 论文里那个"真动手前先在脑子里把几条路各彩排一遍、挑最好的再执行"——这对金融这种"错一步有真实后果"的场景是天生契合的。落到京小贝：让智能体在真正调用下单/转账/查征信这类有副作用的接口前，先在内部"干跑"一遍完整流程、自查会不会出错，确认没问题再碰真接口。这就是一个"dry-run（空跑演练）后再执行"的护栏，既能提升成功率（论文里白赚 4~6 个点），又能挡住危险动作。提示词层面你今天就能试：给智能体加一句"先在内部推演这次工具调用会返回什么、会不会出错，推演通过再真正执行"。
  1. "光多想没用、得先学进去"这条要记牢。 论文那个反直觉发现——没内化世界的模型，让它测试时多想反而更差——对你判断"该不该给智能体加更多测试时算力"是一记提醒：test-time compute（答题时多花算力）不是万能药。如果模型对你的业务世界（金融产品、用户行为、接口脾气）本身就没内化，让它"多想几遍"只会把错误放大。正确顺序是：先让它把你的业务世界学进权重（内化），再谈测试时多想。 顺序反了，加算力=加噪声。这条能帮你在资源分配上少踩坑：与其盲目堆推理算力，不如先确认"世界"进没进模型的脑子。
