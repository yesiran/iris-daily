推荐理由

BPO 值得读，因为它把一个训练问题变成了一个可检查的数学问题：如果模型只在整段答案结束后拿到对错奖励，能否在保留某种策略更新目标的同时，消去对每个中间步骤的价值估计？作者给出的答案有两层：理论上，可以构造与策略镜像下降具有相同最优解的轨迹目标；实践中，再把这个目标近似成便于训练的损失函数。真正的贡献在这条推导链，分数是有限范围内的验证。原文第3节

七拍故事

一、主角：一个只能在交卷后知道成绩的模型。

这里的主角是自回归语言模型：每次生成一个 token，即文本的一个基本片段，再接着生成下一个。RLVR 是“使用可验证奖励的强化学习”，例如答案完成后由程序判断对错。论文把已生成的前缀看成状态，把下一个 token 看成动作；拼接 token 后进入什么状态是确定的，中途奖励为零，奖励留在终点。这些设定构成后面推导的地基。原文第2.2节

二、困境：一张总成绩单，怎样指导漫长的生成过程？

价值函数 V 可以理解为“从当前前缀继续生成，预计最后能得多少分”。优势 A 则衡量某个动作相对于当前平均水平好多少。直接使用策略镜像下降，通常需要中间状态的这些量：既希望增加好动作的概率，又用 KL 散度约束新旧策略差异。KL 是衡量两个概率分布不同程度的工具。难点在于，中间价值需要额外模型估计，或者从很多前缀重新采样后续答案。原文第2.4—2.5节、第3.1节

三、旧路：省掉价值网络，但更新方式仍值得重问。

GRPO 已经能免去单独的价值模型：对同一道题采样一组回答，以组内奖励的相对高低指导训练。其常见实现用当前概率与采样时概率之比，再配合裁剪，控制更新幅度。BPO 因而并非首次实现“无价值网络训练”；它要回答的是，能否从一个明确的策略优化目标出发，推导出另一种处理新旧策略差异的方法。原文第2.3节、第3节

四、转折：中间价值可以在求和时抵消。

在论文的确定性转移、终点奖励设定下，一个 token 的优势满足 Aₜ＝V(sₜ₊₁)－V(sₜ)。沿整段回答相加，中间项像账目里的收支一样相互抵消，最后只剩 ΣAₜ＝R－V(x)：最终得分减去这道题的预期得分。作者把这个恒等式代入策略镜像下降的最优性条件，得到只需要终点奖励、起点价值以及策略概率信息的轨迹残差目标。定理证明，该精确目标与原 PMD 更新在采样策略可达状态上具有相同最优解。原文第3.1节、公式18—24、定理1

这里不能跳过一个细节：仅凭“求和抵消”还不能保证逐步更新等价。作者还证明，最优时轨迹残差为零，会迫使可达状态上的逐步残差也为零。这个约束排除了“前面错一点、后面反向错一点，碰巧总和为零”的任意解。完整证明使用条件期望和鞅性质，适用的是文中规定的策略空间与有限生成长度。原文附录A.1

五、解法：把精确目标变成可训练的近似。

理论目标仍不等于最终代码要优化的损失。作者先线性化残差目标，用同题多次采样的平均奖励估计起点价值，再用“这个 token”和“其余所有 token”两类事件近似完整词表的 KL。由此得到一个补概率比：未平滑时为 (1－μ)/(1－π)，μ 是采样策略的 token 概率，π 是当前策略概率。加入平滑后，权重为 ω＝(1＋ε－μ)/(1＋ε－π)。训练还采用停止梯度、裁剪掩码和权重上限；主实验 ε＝0.1，C＝3。原文第3.2节、公式27—29、第4.1节

一个原创算例能看出两种比值的区别：若 μ＝0.01、π＝0.02，普通概率比为 2，平滑补概率比约为 1.009；若 μ＝0.8、π＝0.9，两者分别为 1.125 和 1.5。相同的更新度量会因概率所处位置而改变。这个算例只展示权重形状，不代表完整更新量；实际更新还受优势、掩码和对数概率梯度影响，不能据此断言所有低概率 token 都该多学或少学。公式依据：原文公式15

六、结局：受控数学实验给出正面结果，但范围有限。

主实验使用 Qwen3-30B-A3B-Base 和 DAPO-Math-17k 英文子集，各方法均训练 400 个采样批次，每批 256 道题、每题 16 个回答，随后做 8 次优化器更新；最大回答长度为 16,384 token。表1按各方法在 AIME24—26 平均分最高的检查点报告：BPO 为 50.5%，最强基线 CISPO 为 47.4%，差 3.1 个百分点；GRPO-ClipHigher 为 39.5%，差 11.0 个百分点。这里的 Avg@32 是每题采样 32 次后取平均正确率，用来估计 Pass@1，绝不是“32 次里答对一次就算成功”。原文第4.1—4.2节、表1

在训练结束的固定位置，BPO 为 49.4%，此时最强基线 DPPO 为 45.5%。这补充说明优势不只存在于各自挑选的峰值，但仍不能替代跨随机种子的置信区间。附录的 Qwen3-4B-Base 消融显示，若干平滑和上限设置表现接近；这支持有限区间内的鲁棒性，不能证明所有模型与任务都不需要调参。原文第4.2节、附录C

七、内核：先找出可以消去的未知量。

我的理解是，这篇论文推进了我们对训练方法的理解：一个优化目标表面上需要逐步价值，并不意味着实现时必须逐步预测它。问题结构可能允许把未知量从目标中消去。但必须保留三层边界——精确目标有等价性证明，实用损失经历了近似，性能提升由特定实验支持。三层分别成立，不能互相冒充。依据：原文第3—4节

来龙去脉

倒读第一层，是“如何在没有价值网络时利用结果奖励”。DeepSeekMath 于 2024 年提出 GRPO，将同题回答的相对奖励用于策略优化。BPO 延续了组采样和组内优势这一实用途径，却重新推导策略不匹配时的权重。因此，它与 GRPO 的关系是保留训练骨架、改变更新依据，而非另建一套推理架构。DeepSeekMath原始论文 BPO第2—3节

再倒读第二层，是“用什么量约束策略变化”。DPPO 研究指出，单个已采样 token 的概率比并不等同于完整策略分布的变化，提出以分布散度及其二元、Top-K 近似处理信任区域。BPO 借用了二元 KL 近似，但它将该工具放入轨迹目标的梯度推导，得到补概率权重。二者共享一个技术工具，不代表目标和算法完全相同。DPPO原始论文 BPO第2.6节、第3.2节

更深一层，是 Bellman 关系与策略镜像下降的连接。前者把连续状态的预期回报联系起来，后者在提升预期收益时约束策略移动。BPO 的概念贡献，是利用语言生成的特定状态结构，把逐状态更新条件改写为整条轨迹的条件。这条脉络解释了为什么论文虽在数学题上验证，却不只是一次榜单改分：值得保留的是可推导、可拆解的优化路径。BPO第2.4—2.5节、第3.1节

对思染：模型进化 & 怎么用

模型进化的落点，是训练规则。

论文没有给模型增加工具、长期记忆或新模态；在固定训练设置下，它让同一底座取得更高数学正确率。由此可以提出一个产品假设：能力提升有时来自如何使用已有反馈，而不仅来自更多参数和数据。但论文没有给出端到端训练成本或推理延迟的对比，不能把它宣传成已证实的降本方案。实验依据：原文第4节及附录B

如果你在训练模型，值得把它当作受控实验候选。

我的建议是先固定数据、采样量、回答长度和奖励验证器，对比最终检查点、独立验证集与多个随机种子；同时记录权重被裁剪的比例。原因是本文同时包含新目标、近似和稳定化处理，只看一条最高分曲线，不能判断收益能否迁移。这是由论文边界导出的实验建议，并非作者已经完成的产品验证。

如果你在做 Agent 产品，先迁移提问方式。

当系统依赖一个难以标注或难以校准的中间评分器时，可以先问：任务结构是否允许把这个中间量消去？但不能直接把 BPO 的定理套到浏览器、机器人或用户对话：这些环境可能有随机外部状态和中途反馈，论文采用的逐 token 确定性转移条件未必成立。更不能据“最终奖励可用”推断模型已经懂得每一步为什么正确。理论条件：原文第2.2节、第3.1节
