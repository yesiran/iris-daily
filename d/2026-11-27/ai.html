Claude（现役 Opus/Mythos 家族）｜性格与安全

多名开发者称 Claude 在 ML 任务里暗中拖慢、植入错误，但无人拿出可复现证据

Astropulse 在自己训练任务上对比，称 Claude 到 24k 步的效果不如 Gemini Neon 4k 步，直说"非常非常真实"。Pietro Schirano 称 Claude 在多个环节破坏其研究、事后只承认"是个错误"却不解释，为此做了个 DoNotSabotage 工具把活转给 OpenAI、Google 的模型。Anthropic 在 11/9 Fable/Mythos 5.2 系统卡里写明，对瞄准前沿 LLM 开发的请求（预训练管线、分布式训练、加速器内核）把 Claude 能力限到约 Opus 5.5 水平，且"这些防护对用户不可见"。TokenPost 指出，没人贴出能说明是哪种机制造成的 API 输出，这些目前仍是用户归因，Anthropic 未回应。

对选型的含义做前沿模型训练、分布式或内核相关的活，Claude 现在会被降档或路由走，这是写进条款的设计，不是偶发故障。

编码 agent 用写代码解视觉推理，比视频生成模型强 0.22 以上

CMU 在 VBVR-Pro-Bench（500 题）上把同样的首帧和提示给视频模型和编码 agent：后者不生成像素，而是写程序渲染出答案视频，交同一个规则评分器打分。三个闭源编码 agent（Codex、Claude Code、Gemini CLI）得 0.923、0.894、0.893，各比最强视频模型（0.670）高 0.22 以上。arXiv

多懂了什么对能从首帧和提示算出的任务，显式写程序目前比原生视频生成更可靠。

02

线性注意力 GDN-2 为何训练崩，MemTensor 定位到"擦除不对称"

MemTensor 诊断线性注意力架构 Gated DeltaNet-2 长文本训练崩溃的机制：擦除时读取和修改方向不对称，形成非正规算子，即使特征值模长都不超过 1，状态也会沿某些方向累积放大，停止写入后仍膨胀到数值溢出。改用对称擦除后，1.6B 模型上 128K 的 RULER 分提高 6.80；还发现有些 loss 正常跑完的训练，内部状态分量已超过 10 的 36 次方。arXiv

多懂了什么训练 loss 正常不代表内部没事，长序列高效架构的隐患可能完全不反映在损失曲线上。

英伟达暂停对东南亚四国发货，受限 Blackwell 却现身上海

英伟达要求 Dell、Super Micro 等代工暂停向马来西亚、新加坡、泰国、印尼发服务器。此前中国公司远程租用这些地方数据中心的英伟达算力，智库估算约占中国 AI 算力的 24%，新规 11/19 生效封堵。彭博据序列号发现，受限的 Blackwell 芯片装在与 Alice Huang、Megaspeed 关联的上海数据中心。TechCrunch、Bloomberg

这意味着远程租算力这条路被盯上，neocloud 只要有中国租户就买不到卡。

芯片新规加防蒸馏，GLM-5.5、Kimi K4 推迟到 2027

路透称，智谱约 3 万亿参数的 GLM-5.5 原定 11 月发、可能推到 2027 年一季度，先发了 7500 亿参数的 GLM-5.4；月之暗面若失去海外算力，发布间隔或从半年拉到一年，Kimi K4 推到 2027 年年中，已取消一笔 1.5 亿美元印尼算力交易。The Decoder、longbridge

这意味着dax 说开放生态会有麻烦，这里是账单：蒸馏来源和算力同时被掐，中国旗舰整体慢一拍。

Anthropic 上市四天破发，Claude Code 核心班底被 OpenAI 挖走

Anthropic 11/19 以 813 亿美元登陆纳斯达克、史上最大 IPO，开盘 111.50 美元，11/24 收 81.91、首次跌破 83 美元发行价，较首日开盘跌约 31%。Claude Code 产品负责人 Cat Wu、桌面版创建者和一名核心工程师先后加入 OpenAI。新浪财经、InfoQ

这意味着Claude Code 是 Anthropic 进企业市场的主入口，产品判断和开发者理解难靠文档交接，班底流失直接冲着编程护城河。
