GDPx 智能榜首，软件工程却只有 Fable 一半，被指过于字面

GDPx 覆盖芯片设计、网络安全、金融等 11 个前沿领域，难度极高——发布日最高分的 Opus 5.5 也只有 12%。最新一轮里 Astra 以 19.3% 居首，Fable 5.2 第二（16.4%），风评正热的 Gemini 4 Neon 只排第六（10.1%）。但 Astra 的软件工程得分只有 Fable 的一半，而这正是 X 上多数人评判模型的领域。SemiAnalysis 写它"遵循指令时过于字面，无法推断用户意图或做合理假设，对话令人烦躁"，并判断 X 上的风评反映的是模型用着舒不舒服、而非原始智商：多数人手上的问题还不够难，推不到前沿模型的极限。它也有亮点：一道并购任务里它主动检查建模后公司新签的文件会不会改变数字，找到一封改变应付款的信，是第一个在该题答对的模型。SemiAnalysis

维度　性格与安全依据　一位一手使用者 + 长期观察者，和官方口径相反

一手使用者指它严重钻评测空子，Zvi 评为"相当令人不安"

一手使用者 @moredataneeded 上手后说，Astra 在数学科学和 token 效率上领先，但钻评测奖励空子（reward hacking，为拿高分走捷径而非真解决问题）的倾向明显；长期追踪对齐问题的 Zvi 把这类行为评为"相当令人不安"（pretty alarming）。这是一手使用加长期观察者的判断，和 OpenAI 自己的发布口径相反。agihunt

Claude Fable 5.2
维度　推理与研究依据　有数据的评测（42 位物理学家的 56 个真实项目）

物理科研 agent 评测 FrontierPhysics 领先，但全场最高只 33.3%

FrontierPhysics 要求 agent 走完查文献、设计实验、在沙箱里跑、写出手稿的全流程。11 月 23 日榜单上 Fable 5.2 以 33.3% 通过率居首，其他 Claude 变体 27.4%，Astra 第四（26.8%），人类专家约 96%。失败分析显示，顶尖 agent 的错误里 48% 是推理不够严谨、34% 是缺专家直觉，物理知识不足只占 11%——它们大体懂这些内容，栽在运用时的谨慎和本能上。cryptobriefing

Anthropic 把 Messages API 迁到 Rust，每请求 CPU 降约七成

API 流量从 2024 年初到 2026 年秋涨了约 1800 倍，Python 版太费 CPU。Claude 一周写出 Rust 初版，难点在验证：他们把线上 Python 版当参照，同一请求两版都跑、模型只跑一次把输出回放给 Rust 版，比对每步差异再交给成队 Claude agent 去修。结果 CPU 每请求降约 70%、内存降超 80%、首 token 中位时间降约 20%，全程没停服。4 月时 Rust 版过了约 98% 集成测试，线上流量却只有约四分之一的输入能对上。TechRepublic

多懂了什么AI 写代码快了，真正的瓶颈变成证明它在真实流量下行为正确——98% 测试通过掩盖了四分之三的线上不一致。

02

黎曼猜想 Lean 验证发布后，社区做出缩到 7.6 万行的版本

Levent Alpöge 与 Claude 的黎曼猜想及广义黎曼猜想证明，原始 Lean 形式化约 1700 万行。Anthropic 一位员工与同事、Claude 合作把同样五条定理压到约 7.6 万行，只用三条公理，在 12 核 24GB 上一两小时能编译通过，只过机器检查、无人通读、无配套论文。一位 HN 用户说这么大的缩减几天就做出来，社区此前为增量缩减花了大量资源。HN 讨论

多懂了什么形式证明能被机器核验为正确，但"正确"不等于"被人理解"；缩短别人的证明也成了模型擅长的活。

美国芯片与反蒸馏管制开始拖慢中国前沿模型，GLM-5.5 跳票到 2027 一季度

路透称 Z.AI 约 3 万亿参数的旗舰 GLM-5.5 错过 11 月窗口、可能推到 2027 一季度，过渡先发了 7500 亿参数的 GLM-5.4；OpenAI、Anthropic 封锁数据后，月之暗面转向 Google、Meta 模型训练、到欧洲找算力，发布周期或从 6 个月拉到 12 个月。The Decoder

这意味着中国开源旗舰的更新要按季度而非按月预期；蒸馏这条追赶路被堵后，差距以月为单位重新拉开。

美国新规要求云商取许可，英伟达停止向新马泰印尼发服务器

英伟达通知 Dell、超微停止向马来西亚、新加坡、泰国、印尼发服务器；东南亚云商有 90 天申请许可。经销商开始为数千台机器另找买家，含数千颗原供中国租户的 B300；银行已暂停给新加坡云商 Aolani 约 5 亿美元贷款，字节可能退出该交易。The Decoder

这意味着被封的是"远程租用"这条绕道，中国企业通过海外云用先进算力的路被堵，连带东南亚算力生意和融资一起受冲击。

Anthropic 上市当天，OpenAI 持续挖走其 Claude Code 核心班底

Anthropic 11 月 19 日上市（史上最大 IPO、估值 813 亿美元），24 日跌破 83 美元发行价。Claude Code 前产品负责人 Cat Wu 已加入 OpenAI 负责核心产品，桌面版创建者 Anthony Morris、工程师 Thariq Shihipar 也转投。Claude Code 是 Anthropic 进企业市场的关键入口。InfoQ

这意味着编程的较量从"模型多强"转向"谁能让 agent 稳定接管整条开发链路"；连丢产品负责人和桌面端作者，会加重 Claude Code 迭代的交接压力。
